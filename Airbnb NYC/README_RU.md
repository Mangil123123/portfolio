# 🏠 Дашборд анализа рынка Airbnb в Нью-Йорке

![Airbnb Dashboard](images/Airbnb_dashboard.png)

## 🇷🇺 О проекте

Интерактивный дашборд в Power BI для анализа рынка краткосрочной аренды в Нью-Йорке.

## 🎯 Бизнес-задача

**Контекст:** Инвесторам в short-term rental нужны данные для принятия решений о максимальной доходности. Неправильный выбор района или типа жилья может привести к убыткам вместо прибыли.

**Задача:** Провести анализ рынка для выявления лучших инвестиционных возможностей:
- В каких районах больше всего объектов?
- Какие типы жилья наиболее распространены?
- В каких районах самые высокие средние цены?
- Какой уровень заполняемости по NYC?
- Какие районы предлагают лучший инвестиционный потенциал?

**Бизнес-ценность:** Инвестиционные решения на основе данных могут увеличить доход от аренды на 20-40%.

## 🛠️ Инструменты
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query (очистка и трансформация данных)
- CSV (источник данных)

## Что я сделал

### 1. Подготовка данных
- Импортировал датасет Airbnb Open Data (~102,000 объектов, NYC)
- Очистил данные в Power Query:
  - Исправил опечатки в названиях районов ("brookln" → "Brooklyn", "manhatan" → "Manhattan")
  - Обработал пропущенные значения ("Not Specified" → отфильтровано из анализа)
  - Проверил типы данных и удалил ошибки
- Создал Date Table для работы с временными данными

### 2. DAX-меры

**Total Listings**



Мера:
```dax
Total Listings = COUNTROWS('Airbnb_Open_Data')
```

**Average Price/Night**



Мера:
```dax
Average Price/Night = AVERAGE('Airbnb_Open_Data'[price])
```

**Occupancy Rate**



Мера:
```dax
Occupancy Rate = DIVIDE(365 - AVERAGE('Airbnb_Open_Data'[availability_365]), 365)
```

**Avg Reviews/Month**


Мера:
```dax
Avg Reviews/Month = AVERAGE('Airbnb_Open_Data'[reviews_per_month])
```

## 📈 Ключевые инсайты
- **Лидер рынка:** Manhattan — больше всего объектов (~27,000)
- **Структура жилья:** 52.38% — entire home/apartment
- **Лидер по цене:** Staten Island — самая высокая средняя цена ($445) среди районов
- **Заполняемость:** средний occupancy rate — 61%
- **Качество данных:** найдены и исправлены опечатки в названиях районов, отфильтрована категория "Not Specified"

## 💡 Рекомендации
1. **Для инвесторов:** Staten Island — для премиум-ценообразования, Manhattan — для объёма
2. **Тип жилья:** фокус на entire home/apt (52% рынка)
3. **Качество данных:** всегда валидировать названия районов в датасетах Airbnb
4. **Насыщенность рынка:** Brooklyn — хороший баланс между количеством объектов и конкуренцией
