# 📉 Дашборд анализа оттока клиентов Telco Customer Churn

![Telco Customer Churn](Images/Churn_Dashboard.png)

## 🇷🇺 О проекте

Минималистичный дашборд в Power BI для анализа причин и стоимости ухода клиентов телеком-оператора.

### 🎯 Бизнес-задача

**Контекст:** Телеком-оператор обслуживает 7 043 абонентов телефонии и интернета (Калифорния). Около 26% клиентов прекращают обслуживание, каждый уход означает потерю рекуррентной выручки.
**Задача:** Создать единое окно мониторинга оттока, отвечающее на вопросы:
- Каков общий уровень оттока и сколько выручки теряется?
- Какой тип контракта наиболее рискован?
- Какие интернет-тарифы генерируют основной отток?
- На каком этапе стажа клиенты уходят чаще всего?
- Есть ли различия в оттоке по демографии?

**Бизнес-ценность:** Удержание существующего абонента дешевле привлечения нового. Сегментация по риску ухода позволяет направить ресурсы на критические группы до момента расторжения, а не постфактум.

## 🛠️ Инструменты

- Power BI Desktop
- DAX
- Power Query (очистка и трансформация данных)
- CSV (источник данных)

## Что я сделал

### 1. Подготовка данных
- Переименовал столбцы под читаемый вид: `customerID` → `CustomerID`, `gender` → `Gender`, `tenure` → `Tenure`, `MonthlyCharges` → `MonthlyRevenue`.
- Задал типы данных: `Tenure` — Whole Number, `MonthlyRevenue` — Decimal Number, `Churn` — Text.
- Заменил значения в столбце `Churn`: `Yes` → `Left`, `No` → `Stayed` (единый вид для фильтров и мер).
- Создал условный столбец `Experience segment` по стажу: `Tenure ≤ 12` → `Novice`, `≤ 24` → `Mid-term`, иначе → `Loyal`.

### 2. DAX-меры

**Total Customers**
```dax
Total Customers = COUNTROWS('Telco')
```

**Churned Customers**
```dax
Churned Customers = CALCULATE([Total Customers], 'Telco'[Churn] = "Left")
```

**Lost Revenue**
```dax
Lost Revenue = CALCULATE(SUM('Telco'[MonthlyRevenue]), 'Telco'[Churn] = "Left")
```

**Churn Rate %**
```dax
Churn Rate % = DIVIDE([Churned Customers], [Total Customers], 0)
```

**Avg Tenure (Months)**
```dax
Avg Tenure (Months) = AVERAGE('Telco'[Tenure])
```

### 3. Визуализация
- **KPI-карточки** — Churn Rate, Lost Revenue, Avg Tenure с png-иконками. Карточка Avg Tenure отфильтрована на уровне визуала по `Churn = Left`, поэтому показывает средний стаж ушедших (17.98 мес. → 18), а не всей базы (32.37 мес.).
- **Bar Chart** — отток по типу контракта (`Contract` × `Churn Rate %`).
- **Donut Chart** — распределение ушедших по интернет-тарифам (`InternetService`, фильтр уровня визуала `Churn = Left`).
- **Column Chart** — ушедшие клиенты по когортам стажа (`Experience segment` × `Churned Customers`).
- **Table** — детализация по демографии (`Gender`, `Senior Citizens`, `Total Customers`, `Churn Rate %`), сортировка по оттоку.
- Подписи данных включены на столбчатых диаграммах для мгновенного чтения.

### 4. Дизайн
- Строгий минимализм: фон `#EEEEEE`, карточки `#FFFFFF`, скругления 30px.
- Убраны рамки и дублирующиеся заголовки. Числовые оси и горизонтальные сетки оставлены на столбчатых диаграммах для чтения масштаба; значения дополнительно продублированы подписями данных.
- Цветовая схема: синий, белый, серый.
- Иконки интегрированы внутрь KPI-карточек через визуализацию image.
- Спарклайны не использованы: в датасете нет временной колонки, линия по стажу имитировала бы тренд, которого в данных нет.

## 📈 Ключевые инсайты

- **Общий отток:** 26.54% базы (1 869 из 7 043 ушли), потерянная выручка — $7.62M.
- **Контракт — главный драйвер:** помесячные контракты уходят в 42.71% случаев против 2.83% на двухлетних. Обязательство сроком снижает отток в ~15 раз.
- **Тариф:** оптоволокно (Fiber optic) даёт 69.4% всех ушедших (1 297 чел.), DSL — 24.56% (459), без интернета — 6.05% (113).
- **Стаж:** новички (Novice, 0–12 мес.) уходят массово — 1 037 чел. против 538 лояльных и 294 среднего сегмента. Критический период — первый год.
- **Демография:** различия по полу минимальны (Female 26.92% против Male 26.16%), пол не является значимым предиктором.

## 💡 Рекомендации

1. **Удержание:** сфокусировать ресурсы на первых 12 месяцах обслуживания и на владельцах month-to-month контрактов с Fiber optic.
2. **Контракты:** стимулировать переход на годовые/двухлетние договоры (скидка, бонус) — это снижает отток в ~15 раз (42.71% → 2.83%).
3. **Качество:** провести глубинный анализ сегмента Fiber optic (технические проблемы, онбординг, ценообразование) как источника 69% уходов.
