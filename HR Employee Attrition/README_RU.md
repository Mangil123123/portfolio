## 🇷🇺 О проекте

Интерактивный дашборд Power BI для анализа текучести кадров (employee attrition).

## 🎯 Бизнес-задача

**Контекст задачи:** Замена одного сотрудника стоит компании 50-200% его годовой зарплаты. Высокая текучесть кадров ведёт к миллионным потерям.

**Задача:** Провести диагностический анализ увольнений для выявления факторов риска:
- Какие сотрудники уходят чаще всего?
- В каких отделах самая высокая текучесть?
- Какие факторы (зарплата, переработки, стаж) влияют на увольнения?
- Кто находится в группе риска прямо сейчас?


**Ценность для бизнеса:** Снижение текучести на 10% экономит миллионы долларов.

## 🛠️ Инструменты
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query (очистка и трансформация данных)
- CSV (источник данных)

## Что я сделал

### 1. Подготовка данных
- Импортировал HR Analytics датасет (~1,470 сотрудников, 35 полей)
- Очистил данные в Power Query: проверил типы данных, удалил ошибки
- Создал вычисляемые столбцы:
  - `Age Group` (18-25, 26-35, 36-45, 46-55, 55+)
  - `Salary Band` (Low, Medium, High, Very High)

### 2. Меры на DAX

**Total Employees**

<img src="images/Total_Employees.png" alt="Total_Employees" width="230">

Мера:
```
Total Employees = COUNTROWS('HR')
```
**Employees Left**

<img src="images/Employees_Left.png" alt="Employees_Left:" width="230">

Мера:
```
Employees Left = 
CALCULATE(
    COUNTROWS('HR'),
    'HR'[Attrition] = "Yes"
)
```
**Attrition Rate %**

<img src="images/Attrition_Rate_Percent.png" alt="Attrition_Rate_%:" width="230">

Мера:
```
Attrition Rate % = 
DIVIDE(
    [Employees Left],
    [Total Employees],
    0
)
```
**Avg Salary**

<img src="images/Avg_Salary.png" alt="Avg_Salary*:" width="230">

Мера:
```
Avg Salary = AVERAGE('HR'[MonthlyIncome])
```
**Avg Age**

<img src="images/Avg_Age.png" alt="Avg_Age*:" width="230">

Мера:
```
Avg Age = AVERAGE('HR'[Age])
```
